# Contributing

Thank you for helping. Issues and pull requests are welcome in English or Arabic.

1. Open an issue first for anything larger than a small fix.
2. Run `cargo fmt`, `cargo check -p yoyo-app` and `cargo test -p yoyo-core` before you send a pull request.
3. Keep logic out of `.slint` files, and put colours and sizes in `ui/theme/tokens.slint`.
4. **Draw it yourself.** Never add icons, images, code or text taken from another player. Say where every asset comes from.
5. Sign off your commits (`git commit -s`) to state that you wrote the change and may submit it under GPL-3.0-or-later ([Developer Certificate of Origin](https://developercertificate.org)).

For a bug report, include your Windows version, your graphics card, and what kind of file it was (container and codecs).
